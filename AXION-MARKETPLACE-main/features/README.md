# Features

Feature-based modules that group all related logic for a domain area (components, hooks, services, types, etc.).

| Folder            | Domain                              |
| ----------------- | ----------------------------------- |
| `authentication/` | Sign-in, sign-up, sessions          |
| `products/`       | Digital product catalog and details |
| `categories/`     | Product categorization and browsing |
| `checkout/`       | Purchase flow and payment           |
| `dashboard/`      | User account dashboard              |
| `downloads/`      | Purchased product delivery          |
| `newsletter/`     | Email subscription                  |
| `contact/`        | Contact form and messaging          |
| `search/`         | Product search and filtering        |
