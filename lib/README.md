# Lib

Core libraries and infrastructure code, organized by concern.

| Folder        | Purpose                                                |
| ------------- | ------------------------------------------------------ |
| `supabase/`   | Supabase client setup and helpers                      |
| `auth/`       | Auth utilities and session helpers                     |
| `validation/` | Schema validation (e.g., Zod schemas)                  |
| `storage/`    | File/storage abstractions                              |
| `database/`   | Data access layer and query helpers                    |
| `security/`   | Security utilities (sanitization, rate limiting, etc.) |
